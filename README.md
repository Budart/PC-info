# PC Info

App Windows estilo "Everest": lista hardware/software do PC, copiar itens e salvar relatório TXT.

**Download:** [PCInfo.exe](https://github.com/Budart/PC-info/raw/main/PCInfo.exe)

Compilar: `mcs -target:winexe -out:PCInfo.exe -r:System.Windows.Forms.dll -r:System.Drawing.dll -r:System.Management.dll PCInfo.cs`
